1. ESP / Wallhack

Wallhacks exploit the rendering pipeline by reading entity positions from game memory before the occlusion culling stage. The cheat hooks into DirectX, OpenGL, or Vulkan draw calls to draw bounding boxes, skeletons, or health bars through walls.

Because the game engine knows where every player is at all times (to handle networking and physics), this data exists in memory. The cheat simply reads it before the graphics card decides what should be visible on screen.

2. Aimbot / Aim Lock

An aimbot reads enemy coordinates from memory, calculates the angle between the player's crosshair and the target, then either simulates mouse input or writes directly to the game's view angles.

  • Aim Lock: Instantly snaps the crosshair to the target. Easy to detect due to inhuman speed and precision.
  • Smooth Aim: Uses interpolation to move the mouse gradually, mimicking human reaction time and muscle movement.
  • Auto Headshot: Targets the head bone from the entity skeleton data, accounting for bullet drop, travel time, and target velocity.

3. Aim Assist

Aim assist is a subtler version that only activates when the player is already near the target. It uses an FOV (Field of View) check — if the target is within a set cone in front of the player, the cheat applies a slight "pull" toward the target.

This makes it much harder to detect because the player still has to aim roughly in the right direction, and the adjustments are small enough to look like natural micro-corrections.
